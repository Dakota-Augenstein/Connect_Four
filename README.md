This is the header and Source files for an stm32f429i Discovery board project. With the Hal code this project enables the user to play a rudimentry version of connect four.
It displays three screens a starting screen, gameplay screen, and win screen.
  The Starting screen allows the user to choose between one and two player mode
  The gameplay screen for either one or two player mode looks the same with a difference in gameplay.
  The win screen shows off scores and allows the user or users to play again
